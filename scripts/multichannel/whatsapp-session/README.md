# Sesión de WhatsApp del bot

Ejecutor local separado de Next.js. Usa `whatsapp-web.js@1.34.7` y Chrome/Edge instalado. No requiere coexistencia ni modifica el número Cloud API del CRM. Esta biblioteca usa WhatsApp Web y es un cliente no oficial: no garantiza compatibilidad permanente ni ausencia de bloqueos.

## Uso local

Desde la raíz del proyecto:

```powershell
node scripts/multichannel/whatsapp-session/cli.mjs doctor
npm --prefix scripts/multichannel/whatsapp-session test
node scripts/multichannel/whatsapp-session/cli.mjs connect
node scripts/multichannel/whatsapp-session/inspect.mjs
node scripts/multichannel/whatsapp-session/inspect.mjs --stop
```

Para dejar el ejecutor en segundo plano: `./scripts/multichannel/whatsapp-session/start.ps1`. Conserva el perfil y comprueba que no exista otra copia. No instala una tarea de Windows ni reinicio automático. `-RecoverStaleLock` solo permite retirar el bloqueo tras comprobar dueño, proceso y navegador anteriores; nunca borra la sesión.

`connect` lee la cuenta y la línea del archivo privado `output/multichannel-private/whatsapp-session/worker-config.json`. También admite `--account UUID --line WA-nombre --port 8788 --browser RUTA_ABSOLUTA --expected-phone DIGITOS`. Un arranque no elige automáticamente un teléfono: el propietario escanea el QR desde el WhatsApp que quiere usar. El primer estado listo fija ese número; otro número exige otra sesión. No se abre ni se reutiliza el perfil personal del navegador.

El enlace privado del panel se muestra al arrancar; el token viaja inicialmente en el fragmento y luego en una cabecera. Se guarda también en `panel-access.json`, dentro de la carpeta privada de esa línea. El panel escucha solo en `127.0.0.1` y rechaza origen/Host ajenos. El compositor permite texto manual en chats y grupos ya existentes de la línea seleccionada; cada intento queda en el diario local, hace pausa humana y no se reenvía si el resultado es incierto. No permite reanudar automatizaciones ni cerrar la sesión de WhatsApp. `/api/stop` únicamente detiene el ejecutor local con autenticación. No exponer el puerto a Internet.

Los QR se actualizan según los eventos de WhatsApp mientras el ejecutor esté conectado. No se cierra el navegador por alcanzar cinco renovaciones del QR. Si se prueba otro número después de un fallo, crear otra línea/sesión y conservar el intento anterior; no reemplazar un número ya vinculado.

Las sesiones del navegador, tokens de acceso local, historial y teléfonos quedan excluidos de Git. Son datos privados: en Windows se heredan los permisos de la carpeta; el modo POSIX no demuestra que la carpeta tenga una ACL exclusiva. No compartir ni copiar perfiles a carpetas públicas.

Si el proceso termina abruptamente puede conservar un bloqueo; comprobar que el proceso/perfil ya no esté activo antes de retirar únicamente ese bloqueo. - Se acortó la ubicación del perfil del navegador para Windows, con dueño identificado por el hash completo de cuenta/línea y ubicación persistida. No se movieron ni borraron los perfiles de diagnóstico anteriores sin número vinculado. El arranque espera de forma compatible con cambios de página y solo recupera hasta dos interrupciones iniciales de contexto antes de estar listo. No reintenta envíos. Un arranque atascado se cancela a los 90 segundos.
